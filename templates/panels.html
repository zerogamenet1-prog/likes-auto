1 แผงลูกคืออะไร?

แผงลูก (Child Panel) คือแผง SMM ภายใต้โดเมนและแบรนด์ของคุณ โดยดึงบริการจาก Likes Auto เป็นต้นทาง คุณตั้งราคาสูงขึ้น ส่วนต่างคือกำไร ลูกค้าเห็นแค่ร้านคุณ ไม่เห็นว่าเชื่อมกับเรา

2 เตรียมยอดเงินในบัญชี
  1. เข้า เติมเงิน ด้วยพร้อมเพย์ / ทรูมันนี่ / โอนธนาคาร
  2. ตรวจสอบว่ายอดคงเหลืออย่างน้อย ฿{{ "%.0f"|format(price) }}
  3. กลับมาหน้านี้แล้วค่อยส่งคำขอ
3 ซื้อโดเมนและตั้ง Nameserver
  1. ซื้อโดเมนจากผู้ให้บริการใดก็ได้ (เช่น Namecheap, GoDaddy, Cloudflare, Hostinger)
  2. เข้าเมนู DNS / Nameservers ของโดเมนนั้น
  3. เปลี่ยนเป็นแบบ Custom Nameservers แล้วใส่:

การกระจาย DNS ใช้เวลาประมาณ 5 นาทีถึง 24 ชม. ระหว่างรอสามารถส่งคำขอได้เลย

4 กรอกฟอร์มสั่งเปิดแผง
  1. ใส่โดเมน เช่น mybrand.com (ไม่ต้องใส่ https://)
  2. เลือกสกุลเงินที่อยากให้ลูกค้าเห็นบนแผง
  3. ตั้งชื่อผู้ใช้และรหัสผ่านแอดมิน (เก็บไว้ให้ดี — ใช้เข้าหลังบ้านแผงลูก)
  4. กด ส่งคำขอเปิดแผง — ระบบหักเงินทันที และสถานะเป็น “รออนุมัติ”
5 รอทีมเปิดแผง
  1. ทีมตรวจ DNS + ติดตั้งแผง โดยปกติ 2–24 ชม.
  2. เมื่อพร้อม สถานะจะเปลี่ยนเป็น เปิดใช้งานแล้ว
  3. ถ้าโดเมนยังไม่ชี้ NS ถูกต้อง อาจล่าช้า — เช็คอีกครั้งที่ผู้ขายโดเมน
  4. หากยกเลิกตอนสถานะรออนุมัติ ระบบคืนเงินเข้าบัญชีอัตโนมัติ (ผ่านแอดมิน)
6 เข้าแผงลูกครั้งแรก
  1. เปิดโดเมนของคุณในเบราว์เซอร์
  2. เข้าหลังบ้านแอดมินด้วยชื่อผู้ใช้/รหัสที่กรอกตอนสั่ง
  3. ตั้งโลโก้ ชื่อร้าน สี และข้อความประกาศ
  4. เชื่อม API / นำเข้าบริการจาก Likes Auto แล้วตั้งมาร์จิ้น
  5. เปิดช่องทางรับเงินของร้านคุณ (พร้อมเพย์ ธนาคาร คริปโต ฯลฯ ตามที่แผงรองรับ)
7 วิธีทำกำไร

ซื้อบริการในต้นทุนของ Likes Auto แล้วขายบนแผงลูกในราคาที่สูงกว่า ส่วนต่างคือกำไร

ตัวอย่าง: ต้นทุน ฿20 / 1,000 · คุณตั้งขาย ฿40 / 1,000 · กำไร ฿20 ต่อออเดอร์นั้น

ใช้ตัวคำนวณด้านบนประมาณรายได้ต่อวัน/เดือน และระยะคืนทุนค่าเปิดแผง

8 ติดปัญหาอะไร
  • ยอดไม่พอ → เติมเงิน
  • โดเมนซ้ำ / รูปแบบผิด → ใช้โดเมนอื่นหรือตรวจสะกด
  • DNS ยังไม่ชี้ → รอ propagation หรือติดต่อผู้ขายโดเมน
  • อื่นๆ → เปิดตั๋วที่ ซัพพอร์ต แจ้งเลขคำขอแผงลูก

คำถามที่พบบ่อย

สรุปสั้นๆ ก่อนตัดสินใจเปิดแผง

ต้องมีความรู้เทคนิคไหม?

ไม่ต้องเขียนโค้ด แค่จดโดเมน ตั้ง Nameserver ตามที่ให้ และกรอกฟอร์ม ทีมช่วยเปิดแผงให้

ลูกค้าจะรู้ว่ามาจาก Likes Auto ไหม?

ไม่รู้ แผงเป็นแบบ white-label แสดงแค่แบรนด์และโดเมนของคุณ

ต้องเช่าเซิร์ฟเวอร์เองไหม?

ไม่ต้อง โฮสติ้ง SSL และการดูแลพื้นฐานรวมในค่าเปิดแผงแล้ว คุณจ่ายเฉพาะโดเมนกับค่าเปิดแผง

จำกัดจำนวนออเดอร์ไหม?

ไม่จำกัดปริมาณออเดอร์บนแผงลูก ระบบขยายตามการใช้งาน

เงินลูกค้าเข้าใคร?

เข้าบัญชีชำระเงินที่คุณตั้งบนแผงลูกเอง Likes Auto ไม่รับเงินจากลูกค้าของคุณ

ใช้เวลานานแค่ไหนถึงเปิดได้?

หลัง DNS พร้อม โดยปกติ 2–24 ชม. ขึ้นกับความเร็ว Nameserver ของโดเมน
