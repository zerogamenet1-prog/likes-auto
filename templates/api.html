Quick Start

มาตรฐานเดียวกับแผง SMM ทั่วไป (Perfect Panel / Followiz และแผงอื่น ๆ)

API URL{{ site.url }}/api/v2
HTTP MethodPOST (form-urlencoded หรือ JSON)
Response FormatJSON
CurrencyTHB
CompatiblePerfect Panel · Followiz · Autolikes · แผง reseller อื่น ๆ · curl / PHP / Python / Node

เชื่อมกับแผง SMM ของคุณ

ตั้งเป็น Provider บนแผงใดก็ได้ที่รองรับ API แบบ Perfect Panel

ช่องบนแผงของคุณใส่ค่านี้
API URL{{ site.url }}/api/v2
API Keyคีย์จากหน้า บัญชี
Http methodPOST
FormatJSON / Form (อัตโนมัติ)
  1. เข้าแผงของคุณ → Providers → Add provider
  2. วาง API URL + API Key ด้านบน แล้วกด Sync / Import services
  3. ระบบดึงบริการทั้งหมดจาก Likes Auto พร้อม type (Default / Custom Comments ฯลฯ)
  4. ตั้งราคาขายบนแผงคุณ แล้วเปิดขายได้ทันที

รองรับทุกบริการที่เปิดขาย: ไลค์ ฟอล วิว คอมเมนต์ (ส่ง comments) รีฟิล ยกเลิก และ drip-feed (runs + interval)

Error Handling

ข้อความ error ที่พบบ่อยและสาเหตุ

Error MessageCause
Incorrect API keyคีย์ไม่ถูกต้อง หรือถูกสร้างใหม่แล้ว
Incorrect requestพารามิเตอร์ไม่ครบหรือผิดรูปแบบ
Account inactiveบัญชีถูกระงับ
Incorrect order IDไม่พบออเดอร์ในบัญชีนี้
ยอดเงินไม่พอ / จำนวนไม่อยู่ในช่วงเครดิตไม่พอ หรือ quantity นอกช่วง min–max
บริการนี้ไม่รองรับการเติมยอดบริการไม่มีรับประกัน refill

คำถามที่พบบ่อย

รับ API Key ได้ที่ไหน?

เข้าสู่ระบบแล้วไปที่หน้า บัญชี จะเห็น API Key และสามารถสร้างใหม่ได้

ใช้ภาษาโปรแกรมอะไรได้บ้าง?

ทุกภาษาที่ส่ง HTTP POST ได้ เช่น PHP, Python, Node.js, Go, C# — ส่งเป็น form หรือ JSON แล้วรับ JSON กลับ

เชื่อมกับแผง SMM ของตัวเองได้ไหม?

ได้ ใส่ API URL {{ site.url }}/api/v2 และ API Key เป็นผู้ให้บริการบนแผงของคุณ แล้วออเดอร์จะถูกส่งต่อมาอัตโนมัติ

ตรวจหลายออเดอร์พร้อมกันได้ไหม?

ได้ ส่ง action=status พร้อม orders=1,2,3 (สูงสุด 100 ID ต่อคำขอ)

สถานะออเดอร์มีอะไรบ้าง?

Pending, Processing, In progress, Completed, Partial, Canceled

พร้อมเชื่อมต่อแล้วหรือยัง?

รับ API Key แล้วเริ่มสั่งงานอัตโนมัติได้ทันที
